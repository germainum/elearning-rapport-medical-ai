| Information (FAQ) | Utilisée dans |
|---|---|
| Rapports médicaux remplis et envoyés **en ligne via MedAI**, 7 j/7, 24 h/24, pour les médecins exerçant dans le canton de Vaud (portal-medai.ch). Infos complémentaires : ai-pro-medico.ch | `en-pratique` |
| L'**incapacité de travail se calcule sur la base d'un 100 %**, et non sur le taux d'activité de la personne | `capacite` (encadré), synthèse |
| Un **diagnostic ne mène pas automatiquement** à un degré d'incapacité de gain : seules comptent les conséquences de l'atteinte observables dans le cas individuel | `limitations` (encadré) |
| Une personne en incapacité de travail partielle ou totale dans sa profession **peut être apte à la réadaptation** | `reinsertion` (encadré) |
| **Détection précoce** : le médecin traitant peut et doit communiquer le cas (incapacité de travail ; risque d'invalidité sans date de retour prévisible ; absences répétées sur 12 mois ; jeunes < 25 ans en formation / premier emploi), après en avoir informé le patient, sans son approbation formelle. Seule la personne (ou son représentant légal) peut déposer la demande de prestations | `en-pratique` |
| **Évolution de l'état de santé** : le patient doit l'annoncer à l'AI ; en cas de procédure longue, le médecin peut envoyer un rapport médical actualisé | `en-pratique` |
| Révision des rentes : questionnaire au médecin traitant tous les 2 à 3 ans en cas de maladie chronique | (non utilisé) |
| Dans la majeure partie des situations, l'appréciation se fait sur la base des **indications des médecins traitants** ; expertise seulement dans certaines circonstances | (cohérent avec la vidéo, intro) |
| Formations : **AI Vaud et SVM** (contact : smrsr.ch/contact) ; cours du **CFAI** ouverts à tous les médecins | `en-pratique` |
